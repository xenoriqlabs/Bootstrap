Bootstrap Introduction

Learn the basics of Bootstrap 5 and understand how Bootstrap helps us build modern and responsive websites.

1. What is Bootstrap?

Bootstrap is a popular open-source front-end framework used to build responsive and mobile-first websites.

It provides ready-made CSS classes and JavaScript components that make web development faster and easier.

Bootstrap includes features such as:

  • Responsive Grid System
  • Buttons
  • Forms
  • Cards
  • Navigation Bars
  • Modals
  • Alerts
  • Tables
  • Utilities

2. Why Bootstrap?

Bootstrap helps developers create responsive and professional-looking websites with less custom CSS.

Important advantages:

  • Fast development
  • Responsive design
  • Mobile-first approach
  • Ready-made components
  • Utility classes
  • Consistent design
  • Easy to learn
  • Large developer community

3. Bootstrap vs CSS

CSS is the standard language used to style HTML. Bootstrap is a framework built mainly with CSS, along with JavaScript components.

CSS Bootstrap
Write styles yourself Provides ready-made styles
More customization Faster development
Requires more CSS code Uses utility classes
Complete control Pre-built components
Responsive design is manual Responsive system is built-in

5. Bootstrap 5

Bootstrap 5 is a modern version of Bootstrap that provides a powerful responsive design system, utility classes, components and JavaScript plugins.

Important Bootstrap 5 features:

  • Responsive grid system
  • Flexbox utilities
  • CSS utilities
  • Responsive breakpoints
  • Modern components
  • Improved forms
  • JavaScript plugins
  • Better customization

6. CDN

CDN stands for Content Delivery Network.

A CDN allows us to use Bootstrap files directly from a remote server without downloading them into our project.

Bootstrap CSS CDN:

<link
    href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.8/dist/css/bootstrap.min.css"
    rel="stylesheet">

CDN is useful when we want to quickly start working with Bootstrap.

7. Local Bootstrap Files

Instead of using a CDN, we can download Bootstrap files and keep them inside our project.

A simple project structure can look like this: 

Bootstrap/
│
├── css/
│   └── bootstrap.min.css
│
├── js/
│   └── bootstrap.bundle.min.js
│
└── 01-bootstrap-introduction.html

Then we can connect Bootstrap locally: 

<link rel="stylesheet" href="css/bootstrap.min.css">

8. Basic Bootstrap Structure

Bootstrap commonly uses a container, rows and columns to create page layouts. 

<div class="container">

    <div class="row">

        <div class="col">
            Column 1
        </div>

        <div class="col">
            Column 2
        </div>

    </div>

</div>
